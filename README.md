# Daily Market Journal

Static public market journal.

Publishing rule: review each generated post before sharing. Keep this folder limited to the finished public pages and site assets.

Tracking snapshots are static, cleaned pages generated from the scrubbed board data. Ticker names link to their TradingView chart URL so readers can open the chart without exposing the raw spreadsheet.

Entry fields separate the original/ideal entry from later second-chance entries, so follow-up opportunities do not overwrite the initial thesis.

Snapshot `% From Entry` values are color-coded: green at 10% or better, orange when positive but under 10%, and red when below entry.
